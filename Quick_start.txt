============================================================
  CONFIDENCE-BASED HYBRID ML FRAMEWORK FOR SOC ALERT TRIAGE
  Quick Start Guide — role-based repository layout
============================================================

Run commands from the project root unless a step says otherwise.

Python environment
------------------
  pip install -r requirements.txt

Primary experiment
------------------
  python experiments/primary/train_and_evaluate.py

Reads data/raw/primary/Primary_training_data.xlsx and
 data/raw/primary/Primary_testing_data.xlsx. Writes model files,
metrics, plots, and predictions under artifacts/primary/.

Secondary experiment (independent from primary)
------------------------------------------------
  python experiments/secondary/run_secondary_model.py

Reads data/raw/secondary/Secondary_Train_70.csv and
Secondary_Test_30.csv. Writes its outputs under artifacts/secondary/.
Set IDS_SECONDARY_RESULTS_DIR to use another output directory.

Comparison report (reads saved experiment outputs)
--------------------------------------------------
  python research/comparison/comparison_report.py

Writes its report, metrics table, and comparison plots to
artifacts/comparison/.

Python Dash interfaces
----------------------
Primary dashboard, port 8050:
  python apps/primary-dashboard/dashboard.py

Secondary dashboard, port 8051:
  python apps/secondary-dashboard/secondary_soc_dashboard.py

Both read saved artifacts; train the associated experiment first if you
want to refresh those saved results.

Next.js dashboard
-----------------
  cd apps/web-dashboard
  npm install
  npm run dev

Open http://localhost:3000. The dashboard defaults to mock mode. The
repository does not contain the separate HTTP API service expected by
its API adapter. Setting NEXT_PUBLIC_API_URL only points the UI at an
external service that implements the documented endpoints; it does not
start or create that service.

Cross-experiment ensemble
-------------------------
Run the tests from the project root:
  python -m pytest tests/test_ensemble.py -v

Print the 34-column schema:
  python research/ensemble/ensemble_predict.py schema

Generate a template:
  python research/ensemble/ensemble_predict.py template --output data/samples/ensemble_template.generated.csv

Run inference on a completed CSV:
  python research/ensemble/ensemble_predict.py predict your_file.csv --output predictions.csv

Ensemble inference requires the trained primary and secondary model
artifacts in artifacts/primary/models/ and artifacts/secondary/models/.
It remains a separate component and does not combine the two training
experiments.

Audit and pipeline tests
------------------------
  python -m pytest tests/test_secondary_pipeline.py -v
  python -X utf8 tools/audit_experiments.py

The audit reads the raw datasets and saved experiment artifacts and writes
its audit outputs under artifacts/verified/audit/.

Data and output locations
-------------------------
  data/raw/primary/       Original primary experiment datasets
  data/raw/secondary/     Original secondary experiment datasets
  data/samples/           Input examples and CSV templates
  artifacts/primary/      Primary models and generated results
  artifacts/secondary/    Secondary models and generated results
  artifacts/verified/     Preserved verified outputs and audit records
  artifacts/comparison/   Generated cross-experiment comparison outputs

Raw datasets and generated artifacts are currently tracked in Git. Before
adding new large datasets or model outputs, decide whether to use Git LFS
or external/versioned artifact storage. Do not delete existing tracked
artifacts as part of routine cleanup.
